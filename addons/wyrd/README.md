# Wyrd addon

Generic narrative and dialogue engine for Godot 4. This folder is what a host game copies.

Version `1.0.0` (see `VERSION`). License: MIT, copyright (c) 2026 Corey Patrick Jones (github.com/Trusdan) (`LICENSE`).

This folder contains `compiler/`, `runtime/`, `cli/`, `editor/`, and `plugin.gd`. The language reference is `docs/language.md`, the API reference is `docs/api/index.md`, the host checklist is `docs/host-checklist.md`, and the stable surface is `docs/stability.md`.

Examples in the repository use only the invented village Gullhaven.
