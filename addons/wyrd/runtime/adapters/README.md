# adapters

Typed adapter base classes a host implements. Unimplemented methods `push_error` and return a typed fallback. The fake host in `tests/fake_host` overrides them. `WyrdTimeAdapter.season` answers a `time.season` resolver. `WyrdSpatialAdapter.witnesses_of` answers `witnesses: auto` and defaults to an empty list. `WyrdSpatialAdapter.perceive` answers the witness mode and defaults to `saw` without `push_error`. `WyrdSpatialAdapter.precision` answers `precise` or `coarse` for a place and defaults to `precise` without `push_error`. `WyrdWorldAdapter.members` answers `faction_assigns`. `WyrdWorldAdapter.groups_of` answers belief precedence, in list order, and defaults to an empty list without `push_error`. `WyrdWorldAdapter.candidates` answers a `cast` slot; an empty filter asks for every entity the host will offer. `WyrdElectionAdapter.start_election` is the host hook for `election` succession. The fake host does not register one. `WyrdSkillAdapter.check` answers a choice skill check. The request is a `WyrdSkillCheck`: skill, evaluated args, scene id, choice id, and a seeded `roll` in `[0, 1)`. Wyrd does not interpret them. The fake host does not register a skill adapter. `WyrdAIProvider.request` returns at once; the answer comes later on the main thread. The default is `WyrdNullAIProvider`, which answers nothing.
