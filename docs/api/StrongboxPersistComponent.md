# StrongboxPersistComponent

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node`

Marks its parent node as saved by Strongbox.

Add it as a child of any node to opt that node in. If the parent does not implement `persist_capture()` and `persist_restore()`, the properties named in `properties` are saved and restored instead. All logic lives in [StrongboxRegistry](StrongboxRegistry.md); this node only holds settings.

## Properties

### `persist_id`

```gdscript
var persist_id: StringName = &""
```

An explicit stable id. When empty, the parent's node path inside the scene is used.

### `properties`

```gdscript
var properties: PackedStringArray = PackedStringArray()
```

Parent properties to save when the parent does not implement the capture and restore methods.
