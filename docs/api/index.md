# Strongbox API

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

- [StrongboxCodec](StrongboxCodec.md): Converts plain Godot values to JSON-safe data and back, losslessly and safely.
- [StrongboxEnvelope](StrongboxEnvelope.md): Wraps an encoded save body with a versioned header and a checksum, as JSON text.
- [StrongboxFileStore](StrongboxFileStore.md): Writes save files so a crash or power cut mid-save can never destroy the last good save, and recovers from a damaged file on load.
- [StrongboxMigrations](StrongboxMigrations.md): Upgrades older save bodies to the current shape through small ordered steps.
- [StrongboxPersist](StrongboxPersist.md): The opt-in contract for nodes whose state Strongbox saves.
- [StrongboxPersistComponent](StrongboxPersistComponent.md): Marks its parent node as saved by Strongbox.
- [StrongboxRegistry](StrongboxRegistry.md): Collects and applies the state of every saved node in a loaded scene, by stable id.
- [StrongboxResult](StrongboxResult.md): The outcome of a Strongbox operation: a value on success, or an error code and message.
- [StrongboxSceneWatcher](StrongboxSceneWatcher.md): Restores its parent scene from a [StrongboxWorldStore](StrongboxWorldStore.md) when the scene is ready, and stashes it when the scene leaves the tree.
- [StrongboxService](StrongboxService.md): One place for a game to save and load: slots, the world store, migrations and playtime.
- [StrongboxSlots](StrongboxSlots.md): Named save slots with metadata for a load menu, a quicksave slot and an autosave ring.
- [StrongboxWorldStore](StrongboxWorldStore.md): Remembers the state of scenes that are not loaded, objects spawned at runtime, and global state.
