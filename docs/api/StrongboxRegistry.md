# StrongboxRegistry

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Collects and applies the state of every saved node in a loaded scene, by stable id.

`collect()` returns `{scene_key, nodes: {id: data}, gone: [ids]}` for one scene. `apply()` restores that state into a fresh instance of the same scene. Nodes removed for good (a picked-up item, a destroyed door) are recorded with `mark_gone()` and freed again when the scene is applied. See [StrongboxPersist](StrongboxPersist.md) for the opt-in contract.

## Methods

### `collect`

```gdscript
func collect(scene_root: Node) -> StrongboxResult
```

Collects the state of every saved node under `scene_root`. On success `StrongboxResult.value` is `{"scene_key", "nodes", "gone"}`. Each node's data is checked with [StrongboxCodec](StrongboxCodec.md), so an unsaveable value fails here with the node id in the message. Nothing is collected if two nodes share an id.

### `apply`

```gdscript
func apply(scene_root: Node, data: Dictionary) -> StrongboxResult
```

Restores `data` (from `collect()`) into `scene_root`, by id. Ids in `gone` are recorded and their nodes freed with `Node.queue_free()`. Ids with no matching node are reported, not fatal. On success `StrongboxResult.value` is `{"restored": [ids], "missing": [ids], "freed": [ids]}`.

### `mark_gone`

```gdscript
func mark_gone(node: Node, scene_root: Node = null) -> StrongboxResult
```

Records that the saved `node` was removed for good, so it stays gone in later collects and is freed when the scene is applied. Call it before freeing the node. `scene_root` defaults to the node's `Node.owner`. On success `StrongboxResult.value` is the node's id.

### `gone_ids`

```gdscript
func gone_ids(scene_key: String) -> String[]
```

Returns the ids recorded as gone for `scene_key`, sorted.

### `add_gone_ids`

```gdscript
func add_gone_ids(scene_key: String, ids: Array) -> void
```

Records `ids` as gone in the scene `scene_key`, as `mark_gone()` does for a node. Used to bring back tombstones from saved data.

### `clear`

```gdscript
func clear() -> void
```

Forgets every recorded tombstone (for a new game).
