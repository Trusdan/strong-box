# StrongboxPersist

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The opt-in contract for nodes whose state Strongbox saves.

A node takes part when it is in the group `GROUP`, or when it has a [StrongboxPersistComponent](StrongboxPersistComponent.md) child (then the parent is the saved node).
A saved node either implements both methods below, or its component lists the properties to save in `StrongboxPersistComponent.properties`. There is no automatic reflection over every property.

```gdscript
func persist_capture() -> Dictionary   # returns the node's state (plain values only)
func persist_restore(data: Dictionary) -> void
```

A node's stable id is, in order: `StrongboxPersistComponent.persist_id`, the node's `META_ID` metadata, or its node path relative to the scene root (for example `Props/Chest01`). A scene's key is the scene root's `META_SCENE_KEY` metadata, or its `Node.scene_file_path`.

Scene-root metadata that overrides the scene key.

### `META_SPAWN_ID`

```gdscript

```

Metadata [StrongboxWorldStore](StrongboxWorldStore.md) puts on a node instanced at runtime. The registry skips such a node and everything under it; the world store saves it instead.

## Methods

### `scene_key_of`

```gdscript
static func scene_key_of(scene_root: Node) -> String
```

Returns the scene key for `scene_root`: its `META_SCENE_KEY` metadata if set, otherwise its `Node.scene_file_path`. Empty when it has neither.

### `component_of`

```gdscript
static func component_of(node: Node) -> StrongboxPersistComponent
```

Returns the component attached to `node`, or null.

### `id_of`

```gdscript

```

Returns the stable id of the saved `node` inside `scene_root`.
