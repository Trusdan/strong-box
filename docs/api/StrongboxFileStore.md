# StrongboxFileStore

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Writes save files so a crash or power cut mid-save can never destroy the last good save, and recovers from a damaged file on load.

`write_atomic()` writes `<path>.tmp`, reads it back and checks it, rotates the backups (`<path>.bak1`, `.bak2`, ...), then renames the temp file into place. `read_verified()` returns the newest file that unpacks cleanly. All paths must stay inside `root`. See "Crash safety" in `docs/format.md`.

## Methods

### `write_atomic`

```gdscript
func write_atomic(path: String, text: String) -> StrongboxResult
```

Writes `text` (a [StrongboxEnvelope](StrongboxEnvelope.md) save) to `path` safely. On any failure the previous good save can still be read with `read_verified()`. On success `StrongboxResult.value` is the full path written.

### `read_verified`

```gdscript
func read_verified(path: String) -> StrongboxResult
```

Reads `path`, falling back to `.bak1`, `.bak2`, ... and returns the first that unpacks cleanly. On success `StrongboxResult.value` is a Dictionary: `text` (the file text), `save` (the unpacked header and body), `source` (`"main"`, `"bak1"`, ...) and `failures` (one `{file, code, message}` entry per file tried before it). Leftover temp files older than the main file are deleted; nothing else is.

### `resolve`

```gdscript
func resolve(path: String) -> String
```

Returns the full path for `path` inside `root`, or an empty string if it would leave `root`, points into `res://`, or is not a plain file path.
