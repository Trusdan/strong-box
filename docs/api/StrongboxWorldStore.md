# StrongboxWorldStore

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Remembers the state of scenes that are not loaded, objects spawned at runtime, and global state.

Call `stash_scene()` right before a scene is unloaded and `restore_scene()` after a new instance of it is ready (or add a [StrongboxSceneWatcher](StrongboxSceneWatcher.md) to do both). Nodes spawned at runtime are recorded with `register_spawned()` and instanced again on restore, but only from `res://` paths under `spawn_allow_prefixes`. Global state (autoloads, a player profile) comes from providers added with `register_provider()`. `to_dict()` and `from_dict()` turn the whole store into plain data for a save body.

## Properties

### `scenes`

```gdscript
var scenes: Dictionary = {}
```

Saved state per scene key: `{scene_key: {"nodes": {}, "gone": [], "spawned": []}}`. Each spawned record is `{"id", "parent", "scene_path", "transform", "data"}`.

### `globals`

```gdscript
var globals: Dictionary = {}
```

Saved global state: `{provider_name: data}`. Data for a provider that is not registered is kept and written back.

### `spawn_allow_prefixes`

```gdscript
var spawn_allow_prefixes: PackedStringArray = []
```

The `res://` folders spawned scenes may be loaded from, for example `["res://items/"]`. Empty means nothing can be spawned. Set by the game.

### `registry`

```gdscript
var registry: StrongboxRegistry = <unknown>
```

Tombstones (nodes removed for good). Call `registry.mark_gone(node)` on it.

## Methods

### `stash_scene`

```gdscript
func stash_scene(scene_root: Node) -> StrongboxResult
```

Collects the state of `scene_root` and replaces its stored entry, including the spawned nodes still under it. Call it right before the scene is unloaded.

### `restore_scene`

```gdscript
func restore_scene(scene_root: Node) -> StrongboxResult
```

Restores the stored entry into `scene_root`, a fresh instance that is ready. Spawned nodes are instanced again under their old parent. A scene with no entry is left as it is. On success `StrongboxResult.value` is `{"restored", "missing", "freed",
"spawned"}`, each a list of ids. Every spawn path is checked against the allow-list before anything changes. An allowed path that does not load as a scene is skipped and listed in `missing` as `"<id> (<path>)"`.

### `register_spawned`

```gdscript
func register_spawned(node: Node, scene_path: String, scene_root: Node = null) -> StrongboxResult
```

Records `node`, instanced at runtime from `scene_path`, so it is saved with its scene and instanced again on restore. `scene_root` defaults to the current scene. On success `StrongboxResult.value` is the generated id (`spawn_<n>`).

### `register_provider`

```gdscript
func register_provider(provider_name: StringName, capture: Callable, restore: Callable, priority: int = 0) -> StrongboxResult
```

Adds a global provider. `capture` takes no arguments and returns a Dictionary; `restore` takes that Dictionary and may return a [StrongboxResult](StrongboxResult.md) (see `restore_globals()`). Providers restore in ascending `priority`.

### `unregister_provider`

```gdscript
func unregister_provider(provider_name: StringName) -> void
```

Removes a provider. Its saved data stays in `globals`.

### `capture_globals`

```gdscript
func capture_globals() -> StrongboxResult
```

Calls every provider's capture and stores the results in `globals`, keeping data for providers that are not registered. On success `StrongboxResult.value` is `globals`.

### `restore_globals`

```gdscript
func restore_globals(data: Dictionary) -> StrongboxResult
```

Stores `data` in `globals` and gives each provider its part, in ascending priority (then by name). A provider with no data gets `{}`.
A restore may return a [StrongboxResult](StrongboxResult.md). A failed one stops here: later providers are not called, and that result is returned with its code and value, the message prefixed with the provider's name. It is not logged again; the provider logs its own error. On success `StrongboxResult.value` is `{"order": [names], "results": {name: value}}`: the providers in the order they were called, and the value of each successful [StrongboxResult](StrongboxResult.md) a restore returned. A restore that returns nothing has no entry.

### `to_dict`

```gdscript
func to_dict() -> Dictionary
```

Returns the whole store as plain, codec-safe data for a save body. Stash the current scene and call `capture_globals()` first so they are included.

### `from_dict`

```gdscript
func from_dict(data: Dictionary) -> StrongboxResult
```

Replaces the store's contents with `data` from `to_dict()`. Nothing changes if the data has the wrong shape. Providers stay registered.

### `clear`

```gdscript
func clear() -> void
```

Forgets every scene, spawned node, tombstone and global (for a new game). Providers and `spawn_allow_prefixes` stay.
