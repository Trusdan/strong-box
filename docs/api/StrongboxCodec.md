# StrongboxCodec

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Converts plain Godot values to JSON-safe data and back, losslessly and safely.

`encode()` turns game state into data that `JSON.stringify()` can write. `decode()` turns parsed JSON back into the original values. Decoding never creates objects or runs code, so it is safe on untrusted save files.
Types JSON cannot hold are written as a tagged dictionary `{"$t": "<type>", "v": ...}`. Real numbers are written as plain JSON numbers when that is exact, and otherwise as the 16 hex digits of their IEEE-754 bits. See `docs/format.md` for the full table.

## Methods

### `encode`

```gdscript
static func encode(value: Variant, root: String = "value", max_depth: int = 64) -> StrongboxResult
```

Encodes `value` into JSON-safe data. On success, `StrongboxResult.value` holds the data. On failure, the message names the path to the bad value, starting at `root` (for example `body.player.weapon`).

### `decode`

```gdscript
static func decode(value: Variant, root: String = "value", max_depth: int = 64, max_string_bytes: int = 33554432) -> StrongboxResult
```

Decodes data produced by `encode()`, usually after `JSON.parse_string()`. Refuses unknown tags, badly shaped tags, nesting deeper than `max_depth` and strings larger than `max_string_bytes` in total, without pushing engine errors.

### `tag_for_type`

```gdscript
static func tag_for_type(type: int) -> String
```

Returns the tag name written for values of Variant type `type`.
