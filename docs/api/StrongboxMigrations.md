# StrongboxMigrations

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Upgrades older save bodies to the current shape through small ordered steps.

A game sets `current_version` (its save `schema_version`) and registers one step per version with `register()`. `run()` applies the steps from a save's version up to `current_version`, working on a deep copy so the input is never changed. The addon's own `format_version` has a separate step table, see `format_migrations()`.

## Methods

### `register`

```gdscript
func register(from_version: int, step: Callable) -> StrongboxResult
```

Registers `step`, which upgrades a body from `from_version` to `from_version + 1`. The step receives a Dictionary and must return one. Registering the same version twice, a version below 1, or an invalid Callable fails.

### `run`

```gdscript
func run(body: Dictionary, from_version: int) -> StrongboxResult
```

Upgrades `body`, saved at `from_version`, to `current_version`. On success `StrongboxResult.value` is `{"body": Dictionary, "version": int,
"report": Array}`, where each report entry is `{"from": n, "to": n + 1}` for a step applied. `body` itself is never changed.
Any error Godot logs while a step runs fails that step with `E_MIGRATION_FAILED`, including an error another thread happens to log at the same moment. Steps must be synchronous (no `await`).

### `validate_chain`

```gdscript
func validate_chain() -> StrongboxResult
```

Checks that a step is registered for every version from `min_supported_version` up to `current_version`. On failure the message lists every missing step.

### `format_migrations`

```gdscript
static func format_migrations() -> StrongboxMigrations
```

Returns a migrations object for the addon's own `format_version`, using the internal step table. Its `current_version` is `StrongboxEnvelope.FORMAT_VERSION`.
