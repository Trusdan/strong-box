# StrongboxEnvelope

Inherits: `RefCounted`

Wraps an encoded save body with a versioned header and a checksum, as JSON text.

A save file is one JSON object: `{"body": ..., "header": ...}`. The body is written by [StrongboxCodec](StrongboxCodec.md). The header names the format and its version, carries the game's schema version and labels, and holds a SHA-256 checksum of the body's canonical JSON. `unpack()` checks the format, the version and the checksum before it decodes the body. See `docs/format.md`.

## Methods

### `pack`

```gdscript
static func pack(body: Dictionary, meta: Dictionary, schema_version: int = 1, game_version: String = "", playtime_s: float = 0.0, saved_unix: int = -1) -> StrongboxResult
```

Encodes `body` and wraps it with a header. `meta` holds game-supplied labels for a load menu (for example a location name). On success `StrongboxResult.value` is the JSON text. `saved_unix` defaults to the current time; pass a fixed value for reproducible output.

### `unpack`

```gdscript
static func unpack(text: String, max_depth: int = 64, max_string_bytes: int = 33554432) -> StrongboxResult
```

Parses save `text` and returns `{"header": Dictionary, "body": Dictionary}`. Refuses invalid JSON (`E_JSON`), a wrong layout or header (`E_FORMAT`), a newer format (`E_FORMAT_TOO_NEW`) and a checksum mismatch (`E_CHECKSUM`), in that order, before the body is decoded. Codec errors from the body are passed on.
