# StrongboxSceneWatcher

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node`

Restores its parent scene from a [StrongboxWorldStore](StrongboxWorldStore.md) when the scene is ready, and stashes it when the scene leaves the tree.

Add it as a direct child of a scene's root and set `store` before the scene enters the tree (or before the scene leaves it, for stashing only). Errors are pushed and also sent through `restored` and `stashed`.

## Signals

### `restored`

```gdscript
signal restored(result: StrongboxResult)
```

Emitted after the parent scene was restored, with the result of `StrongboxWorldStore.restore_scene()`.

### `stashed`

```gdscript
signal stashed(result: StrongboxResult)
```

Emitted after the parent scene was stashed, with the result of `StrongboxWorldStore.stash_scene()`.

## Properties

### `store`

```gdscript
var store: StrongboxWorldStore
```

The store to restore from and stash into. Nothing happens while it is null.

### `restore_on_ready`

```gdscript
var restore_on_ready: bool = true
```

Restore the parent when it is ready.

### `stash_on_exit`

```gdscript
var stash_on_exit: bool = true
```

Stash the parent when it leaves the tree.
