# StrongboxSlots

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Named save slots with metadata for a load menu, a quicksave slot and an autosave ring.

Each slot is a folder `<root>/<slot_id>/` holding `save.json` (written by [StrongboxFileStore](StrongboxFileStore.md), with its backups), a small `meta.json` so a load menu can list slots without opening any save, and an optional `thumb.png`.
`meta.json` is a cache: it is a [StrongboxEnvelope](StrongboxEnvelope.md) whose body holds `slot_id`, `kind`, `saved_unix`, `playtime_s`, `schema_version`, `game_version`, `label` and `seq` (a write counter that orders slots saved in the same second). If it is missing or damaged, `list()` rebuilds it from the save's header.

### `write`

```gdscript
func write(slot_id: String, text: String, label: Dictionary = {}) -> StrongboxResult
```

Writes save `text` (from `StrongboxEnvelope.pack()`) to `slot_id`, then its `meta.json`. `label` holds load-menu labels such as a location name; when it is empty, the save header's `meta` is used. On success `StrongboxResult.value` is the slot's metadata. A failed `meta.json` write does not fail the save: `list()` rebuilds it.

### `read`

```gdscript
func read(slot_id: String) -> StrongboxResult
```

Reads `slot_id` through `StrongboxFileStore.read_verified()`, so a damaged save falls back to its backups. On success `StrongboxResult.value` is that method's Dictionary (`text`, `save`, `source`, `failures`).

### `delete`

```gdscript
func delete(slot_id: String) -> StrongboxResult
```

Deletes the folder of `slot_id` and everything in it. Nothing outside that folder, or outside the root, is touched.

### `list`

```gdscript
func list() -> Dictionary[]
```

Returns the metadata of every slot, newest first. Each entry has `damaged`: `true` when the slot's save cannot be read (its other fields may then be empty). Folders that are not valid slots are skipped. A valid `meta.json` is used as is, so listing does not open any `save.json`; a missing or damaged one is rebuilt.

### `latest`

```gdscript
func latest() -> Dictionary
```

Returns the newest slot of any kind, or an empty Dictionary when there are none.

### `next_autosave_id`

```gdscript
func next_autosave_id() -> String
```

Returns the autosave slot to write next: the first empty one in the ring, otherwise the one written longest ago.

### `write_thumbnail`

```gdscript
func write_thumbnail(slot_id: String, image: Image) -> StrongboxResult
```

Saves `image` as the slot's PNG thumbnail, scaled down to fit `THUMBNAIL_MAX`. Never affects the save itself.

### `read_thumbnail`

```gdscript
func read_thumbnail(slot_id: String) -> Image
```

Returns the slot's thumbnail, or `null` if it has none or it cannot be read. Loaded with `Image.load_png_from_buffer()`; no resource loading is involved.
